# Relationship Between Stress Levels and Sleep Quality

## Project overview
This project examines whether perceived stress is associated with self-rated sleep quality using the University of New England research dataset:

**The Relationship Between Stress, Arousal, Sleep Quality & Affective Symptoms**  
Jamieson, G., Brown, R., & Roche-Freedman, K. (2022). University of New England.  
DOI: [10.25952/ydqq-kr29](https://doi.org/10.25952/ydqq-kr29)  
Permanent record: https://hdl.handle.net/1959.11/41021

The repository contains analysis code and documentation. The original workbook and participant-level/processed records are deliberately excluded from Git because the workbook contains sensitive participant responses and the repository record must be checked for specific reuse conditions before redistribution.

## Research question
Is perceived stress associated with self-rated overall sleep quality among participants who completed the survey?

## Hypotheses
- H0: There is no monotonic association between perceived stress score and self-rated sleep quality.
- H1: There is a monotonic association between perceived stress score and self-rated sleep quality.

## Data placement
Download the original Excel workbook from the UNE repository and place it locally at:

`data/raw/opendataset_The Relationship Between Stress, Arousal, Sleep Quality and Affective Symptoms - UNE_January 17, 2022_15.02.xlsx`

Do not commit the workbook. The `.gitignore` file excludes `data/raw/` and `data/processed/`.

## Measures and scoring
- Perceived stress: the ten PSS items exported as `Q20_1` through `Q20_10`.
- Sleep quality: the overall self-rated sleep-quality item exported as `Q46`.
- The PSS items are expected to be coded 1–5 in increasing frequency order. The script converts these to 0–4 and reverse-scores PSS items 4, 5, 7 and 8 before summing. This coding assumption must be checked against the survey response options/codebook before interpreting the score.
- `Q46` is treated as an ordinal single-item rating. The analysis assumes 1 = very good, 2 = fairly good, 3 = fairly bad, and 4 = very bad. Verify this order against the original questionnaire before interpreting direction.
- This project does **not** claim to calculate the full PSQI global score. The workbook includes additional PSQI items, some with free-text/time responses; the primary outcome here is the overall sleep-quality rating item.

## Analysis
The R script:
1. Imports the Excel workbook and removes the embedded question-label row.
2. Keeps completed records and checks required columns.
3. Calculates the PSS-10 total score after reverse scoring.
4. Produces descriptive summaries and three figures.
5. Runs Spearman correlation and an ordinal logistic regression.
6. Writes aggregate outputs only; participant-level data stay local.

## Run the project
1. Install R and RStudio.
2. Open `Stress_Sleep_Analysis.Rproj` (or set the working directory to the project root).
3. Install packages if prompted:
   `install.packages(c("readxl", "dplyr", "tidyr", "ggplot2", "readr", "MASS", "rmarkdown", "knitr"))`
4. Put the downloaded workbook in `data/raw/` using the filename above.
5. Run `code/01_analysis.R` from top to bottom.
6. Open `report/analysis_report.Rmd` and click **Knit** to render the report.

## Repository structure
- `code/01_analysis.R`: import, clean, score, analyse and plot.
- `report/analysis_report.Rmd`: reproducible report template.
- `figures/`: aggregate figures generated by the script.
- `results/`: aggregate summaries and model output.
- `data/raw/` and `data/processed/`: local-only data folders, excluded from Git.

## Limitations
This is an observational, cross-sectional survey. Associations do not establish causation. Self-report measures may be affected by recall and response bias. The analysis uses one overall sleep-quality item rather than claiming a complete PSQI global score. The number of completed usable records is calculated from the supplied workbook by the script; it may differ from the repository abstract's participant count because incomplete or excluded submissions may be present in the export.

## Ethics and data handling
The raw workbook contains participant-level responses and potentially sensitive health information. It is not included in this public repository. Only aggregate tables and figures are intended for publication. Check the dataset's terms and institutional assessment guidance before publishing derived outputs.
